## 3) سياسات المحاسبة

| البند | السياسة |
|---|---|
| الاعتراف بالبيع | تاريخ التسليم الموثّق داخل الشهر (قاعدة الربحية). التسليم بتاريخ غير معروف لا يُسنَد لأي شهر ويظهر تنبيهاً |
| الملغى / قيد التوصيل / المعلّق / التسوية | ليست مبيعات؛ تُعرض كأعداد منفصلة بتاريخ الطلب |
| المرتجع | المكتمل بشهر الإرجاع؛ صافي الكمية = المسلَّم − المرتجع المكتمل بالفترة (قد يكون سالباً لمنتج أُرجع من مبيعات سابقة) |
| تقييم التكلفة | **تكلفة معيارية شهرية مؤرَّخة**: تكلفة السوق ثم الموحّدة السارية بتاريخ ≤ شهر البيع. FIFO/المتوسط المرجّح غير ممكنين بلا تكلفة شراء مسجّلة |
| تكلفة مفقودة | ≠ صفر: «بلا تكلفة» والربح «غير محسوب» + مبيعاتها معروضة منفصلة |
| الهدايا | لا علامة سطر ← غير متاح. الطلب بقيمة 0 صراحةً = «مجاني»: مبيعات 0، تكلفته بعمود منفصل خارج الربح الإجمالي. القيمة الفارغة (null) = «بلا قيمة» |
| العملات | كل عملة على حدة + معادل دولار فقط بسعر شهري معتمد (`profitability_fx_rates`)؛ الأسعار المستخدمة تظهر وتُحفظ |
| الشحن | `orders.amount` لا يشمل رسوم التوصيل؛ تُعرض «رسوم توصيل على الزبون» منفصلة |
| المؤرشف | يُحسب مرة واحدة (ليس جدولاً منفصلاً)؛ لا يُستبعد |
| التكرار | إزالة تكرار بالمعرّف عند تداخل نوافذ الأشهر |
| الربح الإجمالي | المبيعات − تكلفة المنتجات فقط (بلا إعلان/شحن/رواتب — الصافي بتبويب «النتائج الشهرية») |

**لماذا لا Materialized View:** ~1,100 طلب/شهر؛ الحساب يتم بالمتصفح من نفس RPC الموجود بصلاحياته (admin/manager/sales_manager). لا جداول/Views/RLS جديدة.
